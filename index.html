7-Step Methodology

1. Inception & Data Review

Review methodology, metadata, microdata. Assess quality. Develop analytical framework and workplan. DeepSeek: Parses metadata schemas; flags inconsistencies.

2. Validation & Tabulation Plan

Resolve/document data issues. Finalize tabulation plan with CSO approval. DeepSeek: Generates validation queries and tabulation specifications.

3. Analysis & Visualization

Produce tables, cross-tabs, charts, maps. Employment by sex, industry (ISIC Rev.4), size, geography. DeepSeek: Executes analysis via Function Calling; returns structured JSON.

4. Draft Analytical Report

Narrative with findings, policy implications, 2009 comparability. DeepSeek: Assists in generating draft sections from structured results.

5. Stakeholder Validation

Present findings. Manage feedback. Consolidate comments. DeepSeek: Organizes comment-response matrix.

6. Final Report & Documentation

Final report, visualizations, reproducible code package. DeepSeek: Ensures code-snippet fidelity and JSON schema consistency.
